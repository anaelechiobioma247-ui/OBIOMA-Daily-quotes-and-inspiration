# OBIOMA Daily Quotes and Inspiration

OBIOMA is a mobile app project built to share daily quotes, motivation, and inspiration with users in a simple and uplifting experience.

## Overview

This project is designed for Android app deployment and serves as a starter build for a quotes-and-inspiration application. It can be expanded with more features, categories, daily notifications, and custom content.

## Features

- Daily motivational quotes
- Clean and simple mobile interface
- Android-friendly app structure
- Ready for Expo and EAS build workflows
- Easy to extend with more screens and functionality

## Tech Stack

- JavaScript
- React Native / Expo
- EAS Build for Android publishing

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the app locally:
   ```bash
   npm start
   ```

3. Run the app on Android:
   ```bash
   npx expo start --android
   ```

4. Build for Android with EAS:
   ```bash
   npx eas-cli build --platform android
   ```

## Project Files

- `App.js` – main application entry
- `package.json` – project scripts and dependencies
- `app.json` – Expo app configuration
- `eas.json` – EAS build configuration
- `README.md` – project overview and setup instructions

## Notes

This project is intended to be a solid starting point for an Android app focused on daily inspiration, quotes, and personal motivation.
